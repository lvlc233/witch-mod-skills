# Source Map

默认资源根：

```text
../../resources/
```

官方资源：

```text
../../resources/official/
```

## 官方资料

| 路径 | 用途 |
|---|---|
| `official/README.zh-CN.md` | 官方总说明、快速开始、发布说明 |
| `official/ModTemplate/` | Lua Mod 官方模板 |
| `official/ModTemplate/Data/` | Data CSV 样例 |
| `official/ModTemplate/Text/` | Text CSV 样例 |
| `official/ModTemplate/Scripts/Entry.lua` | Lua 入口样例 |
| `official/ModTemplate/Scripts/ScriptSample.lua` | ScriptExecutor 脚本样例 |
| `official/ModTemplate/Scripts/Lib/` | TypeHint 与原版配置参考 |
| `official/DllTemplate/` | C# DLL Hook 官方模板 |
| `official/Example/Defect/` | 官方综合示例 |
| `official/反编译文件夹*.zip` | 反编译资料，按 1.5 级事实处理 |

## 其他资源

用户可以把其他人的 Mod、额外反编译版本、运行记录放在 `resources/` 下。调研时必须写明具体路径，不要把外部参考当成官方事实。
